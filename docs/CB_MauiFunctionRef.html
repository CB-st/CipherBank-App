Runtime conventions

RuleValue
BadgeINVOKE — C# method / RelayCommand (not HTTP)
ProjectsCipherBank-app · CipherBank-app.Core · CipherBank-app.ChallengePass
Session proofLab (default) · ChallengePassA1 · ChallengePassA2
Unlock orchestratorCompleteUnlockAsync — session+stream required; prefs/bootstrap best-effort
Product APIIProductApi → mock or HttpProductApi (/v1)
Public quotesIPublicQuoteService → PublicApiClient (api.cipherbank.money)
Convert lock vs settleLock = public /iquote + 15s client TTL; settle = product ConvertAsync (quote not sent)

SQLite AndroidShip e_sqlite3.android only — exclude desktop natives from APK
Idle lockAppIdleLockService → AppSession.Lock → IPqChannel.Clear → Unlock

Unlock / seal call graph

Splash (≥900ms) + Boot + IdleLock.Start
  → Welcome → Keys(Generate) → BackupQuiz → SetPin.Seal
       → FinishCustodySetup → Seal → Seed(BTC,ETH) → CompleteUnlock(no bootstrap)
  → Unlock.PIN|Biometrics
       → Unlock* → CompleteUnlock(bootstrap)
            → CreateSession (Lab|A1|A2 via ChallengePassSessionProofBuilder)
            → Stream.Connect (disconnect-first) + Hub.Start
            → PrefsSync.PullMerge [+ AccountBootstrap]  // best-effort
  → Home

Idle / Profile.Lock → AppSession.Lock → Locked → PQ Clear → Unlock

Never on the wire

Mnemonic, BIP39 entropy, PIN plaintext, device secret, account private key, spend keys, PAN/CVV, full ACH account numbers. Public/product APIs receive public keys, sealed ciphertexts, handles, and masked last4 only. CryptoBox passphrase for custody is the device secret, not the PIN (PIN is the logical gate).
