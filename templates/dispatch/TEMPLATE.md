# Dispatch definition of done

- [ ] One stable workflow ID and primary CipherBank skill are selected
- [ ] Feature scope and out-of-scope behavior are explicit
- [ ] Owning layers and forbidden dependencies are named
- [ ] Existing shared resources are listed before proposed additions
- [ ] Interface, implementation, composition root, configuration, and tests have destinations
- [ ] Security, secret ownership, cancellation, offline, and failure behavior are addressed where applicable
- [ ] Narrow, structural, build, and device gates are listed in execution order
- [ ] No credentials, customer data, recovery material, private endpoints, or tokens appear in the packet
