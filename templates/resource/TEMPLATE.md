# Shared-resource checklist

- [ ] The existing global dictionaries do not already express the role
- [ ] The key is semantic and feature-prefixed, not a copied visual value
- [ ] Colors have light/dark behavior and sufficient contrast
- [ ] Typography derives from a named global type role
- [ ] Repeated control treatment derives from a global component style where possible
- [ ] The dictionary is merged once at the smallest common scope
- [ ] No duplicate XAML keys are introduced
- [ ] Large text, 44×44 targets, screen-reader meaning, and non-color status cues are verified
- [ ] Cross-feature reuse triggers promotion to the shared resource owner
