POST

/currencies

Returns the currencies currently supported by CipherBank.

Host: api.cipherbank.money · HTTP: 1.1

Request JSON

No JSON request body is required.

Example

{}

Successful response JSON

The supported currency list.

FieldTypeDescription
CURRENCIES array Ordered currency codes currently available to public API customers.

Example

{
  "CURRENCIES": [
    "BITCOIN",
    "MONERO",
    "USD"
  ]
}

Status codes

StatusBehavior
200The supported currency list was returned.
422The wallet service returned an invalid result.
424The wallet dependency was unavailable.
POST

/iquote

Calculates the output amount produced by a requested input amount.

Host: api.cipherbank.money · HTTP: 1.1

Request JSON

FieldTypeDescription
INPUT_AMOUNT number (double) Amount of the input currency the customer will provide.
INPUT_CURRENCY string (currency-code) Currency the customer will provide.
OUTPUT_CURRENCY string (currency-code) Currency in which to calculate the result.

Example

{
  "INPUT_AMOUNT": 0.0015,
  "INPUT_CURRENCY": "BITCOIN",
  "OUTPUT_CURRENCY": "USD"
}

Successful response JSON

A calculated currency conversion quote.

FieldTypeDescription
INPUT_AMOUNT number (double) Amount of the input currency required or supplied.
INPUT_CURRENCY string (currency-code) Currency supplied by the customer.
OUTPUT_AMOUNT number (double) Amount of the output currency requested or calculated.
OUTPUT_CURRENCY string (currency-code) Currency returned to the customer.

Example

{
  "INPUT_AMOUNT": 0.0015,
  "INPUT_CURRENCY": "BITCOIN",
  "OUTPUT_AMOUNT": 100.0,
  "OUTPUT_CURRENCY": "USD"
}

Status codes

StatusBehavior
200A quote was calculated.
406The Accept header does not permit JSON.
415A non-empty body was not sent as application/json.
417The JSON body could not be parsed or did not match the field types.
422The inverse quote request or downstream quote result was invalid.
424The price-cache dependency was unavailable.

/quote

Calculates the input amount required to produce a requested output amount.

Host: api.cipherbank.money · HTTP: 1.1

Request JSON

FieldTypeDescription
INPUT_CURRENCY string (currency-code) Currency the customer will provide.

OUTPUT_CURRENCY string (currency-code) Currency the customer wants to receive.
