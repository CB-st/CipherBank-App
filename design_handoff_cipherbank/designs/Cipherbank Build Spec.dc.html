4 · Application operations (step-by-step)

Every user-facing flow, written so it can be built screen-by-screen. Each operation lists its entry point, the ordered steps, and the states to design for.

OP-01

Instant convert (crypto ⇄ fiat)

ENTRY: Home → Convert · Tab bar → Convert

  1. Pick the from asset and enter an amount; live fiat estimate updates beneath.
  2. Pick the to asset. The rate locks with a visible countdown (e.g. 12s) — re-lock on expiry.
  3. Show the breakdown: rate, network fee ($0 — "we cover it"), privacy mode, settlement = instant.
  4. Confirm → success state: new balances, "ready for ACH, payments, or withdrawal."

States: empty · rate-locked · rate-expired · insufficient balance · success.

OP-02

Pay with a mix

ENTRY: Tab bar → Pay · Bill/recipient deep-link

  1. Select recipient and amount (or pull from a bill, e.g. "Rent · due Jul 1").
  2. Build the funding mix: add sources (crypto, cash, securities), each with a value; a stacked bar shows composition and must total 100%.
  3. Explain mediation: "We exchange in real time — the recipient receives clean USD, never the mix."
  4. Confirm → settlement receipt with per-source breakdown.

States: under-funded (<100%) · over-funded · single-source · multi-source · success.

OP-03

Send / ACH transfer

ENTRY: Home → Send · Tab bar → Send

  1. Choose recipient (handle or linked bank ••••, ACH).
  2. Enter amount and source balance (auto-converts from crypto if needed).
  3. Toggle speed: Instant (Cipherbank rail) vs Standard ACH.
  4. Review: arrival, $0 fee, privacy ("they see a handle, not you") → send → confirmation.

States: instant · standard · cross-asset (converts first) · pending · settled.

OP-04

Accounts & balances (home)

ENTRY: App launch · Tab bar → Home

  1. Cora guide bar at top with a rotating one-liner.
  2. Total balance hero: aggregate USD value, today's change, asset/currency counts, "self-custodied" tag.
  3. Quick actions row: Convert · Send · Pay · Receive.
  4. Asset list: every holding with balance, USD value, 24h change; "Securities coming soon" teaser at the end.

States: funded · new/empty account · value hidden (privacy toggle) · loading.

OP-05

Receive

ENTRY: Home → Receive · Tab bar → Home

  1. Pick which asset/currency to receive into.
  2. Show your handle + QR; optionally request a specific amount.
  3. Share sheet (copy handle, share QR). Note privacy: sender sees only the handle.

States: default · amount requested · received/success toast.

OP-06

Onboarding & key custody

ENTRY: First launch

  1. Welcome + value prop (Cora introduces herself, dryly).
  2. Create self-custodied wallet: generate keys, confirm recovery phrase, biometric lock.
  3. Link a bank for ACH (optional, can skip).
  4. Fund: buy, deposit crypto, or transfer in → land on Home.

States: welcome · key-gen · recovery confirm · bank link · funded · skipped.

5 · Suggested build order

  1. Foundations — tokens, fonts, logo, asset-glyph + UI-icon components.
  2. Home (OP-04) — the shell everything returns to.
  3. Convert (OP-01) — the core promise; reused by Send & Pay.
  4. Send (OP-03) & Receive (OP-05) — money in/out.
  5. Pay with a mix (OP-02) — the differentiator; depends on Convert.
  6. Onboarding (OP-06) — wrap once flows exist to land in.
  7. Securities — extend the asset model; unlock "pay/invest with anything."
